# Bryves TV API-only Render
Render serves API only. `index.html` and `admin.html` are local clients.

Render:
Build: `npm install`
Start: `npm start`

Environment:
`MUX_TOKEN_ID`
`MUX_TOKEN_SECRET`
`FIREBASE_DATABASE_URL=https://bryvestv-default-rtdb.firebaseio.com`
`ADMIN_PASSWORD`

Local:
- open `admin.html` to create the Mux stream automatically
- open `index.html` to watch
